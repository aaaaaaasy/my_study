# 포트폴리오 리디자인 방향

## 컨셉

**Corporate Performance Report** 스타일로 재구성한다.  
H1 Business Performance Report PPT 템플릿에서 영감을 받아, 딥 네이비와 블루 액센트를 중심으로 한 전문적이고 비즈니스스러운 톤을 적용한다. 콘텐츠가 주도하는 포트폴리오에 선명한 정체성과 높은 가독성을 부여한다.

## 시각 시스템

- 배경: 밝은 슬레이트 계열(#f8fafc)과 연한 블루 그레이를 교차해 섹션 간 리듬을 만든다.
- 핵심 영역: 첫 화면을 딥 네이비 히어로로 구성하고, 원형 프레임·얇은 라인·은은한 블루 글로우를 사용한다.
- 타이포그래피: Pretendard와 Noto Sans KR를 조합해 제목은 굵고 압축된 인상, 본문은 읽기 쉬운 밀도로 설정한다.
- 컴포넌트: 카드와 버튼은 16~20px의 둥근 모서리, 섬세한 테두리, 짧은 변형·그림자 전환으로 통일한다.
- 포인트 컬러: 라임 그린 대신 #3b82f6 계열의 블루를 사용한다.

## 사용자 경험 개선

1. 히어로에서 정체성·전문 분야·두 가지 행동 유도(작업 보기, 문의하기)를 바로 제시한다.
2. 데스크톱과 모바일 모두에서 탐색 가능한 반응형 헤더와 모바일 메뉴를 제공한다.
3. 자동으로 큰 임베드 영상을 노출하지 않고, 컨트롤 가능한 영상 프리뷰로 전환한다.
4. 최신 글·자료 카드에 순서, 유형, 태그를 명확히 드러내 스캔성을 높인다.
5. 키보드 포커스, 대체 텍스트, 사용자 동작에 따른 버튼 피드백을 보강한다.

## 데이터 처리 원칙

사용자가 제공한 기존 예시 데이터 구조는 유지한다. 다만 예시 이름·링크·영상은 실제 운영 전 교체가 필요하므로 레이아웃은 임의의 특정 데이터에 의존하지 않도록 구현한다.
